# Superstore Sales Dashboard

# About
This project was completed as part of my Data Analyst Internship. 
The objective of this task was to create an interactive dashboard using the Superstore dataset and present useful business insights through data visualization.

# Tools Used
1)Power BI Desktop
2) Superstore Dataset (CSV)

# Dashboard Overview
The dashboard includes:
1) Total Sales
2) Total Profit
3) Total Orders
4) Average Discount
5) Monthly Sales Trend
6) Profit by Category
7) Sales by Region
8) Sales by Segment
9) Top 10 Products by Sales
10) Bottom 10 States by Profit

# Key Observations
1) Technology is the highest-performing category in terms of profit.
2) The West region has the highest sales among all regions.
3) The Consumer segment contributes the largest share of overall sales.
4) Some states are generating lower profits and may need more attention.
5) The average discount across all orders is around 16%.
